# th06-psp-native

**日本語** | [English](README_EN.md)

東方紅魔郷をPSP上でネイティブ動作させる、非公式・開発途中の移植です。エミュレータではありません。
過去に公開された類似名の`th06_PSP`とは別のプロジェクトです。

> [!WARNING]
> このリポジトリと配布EBOOTには、東方紅魔郷の原作データを一切含みません。
> 動作には、利用者自身が所有するPC版東方紅魔郷1.02fのインストールフォルダが必要です。

## 特徴

- D3D/OpenGLなどの汎用グラフィックスAPIや外部描画ラッパーを使わず、PSP専用backendから
  PSPSDKのlibGU/libGUMを介してGraphics Engine（GE）へコマンドを送るネイティブ描画です。
- m-c/dの[Media Engine Custom Core（MECC）](https://github.com/mcidclan/psp-media-engine-custom-core)を使い、
  PSP実機ではMedia Engine（ME）をPCM音声ミキシングやMIDI合成に利用します。
  MIDIの機種別の動作とフォールバックについては、下記のMIDI演奏の説明を参照してください。
- ゲームの論理解像度640x480を保ち、PSPの480x272へ4:3表示または全画面引き伸ばしで出力します。

## 現在の状態

MIDI対応版のダウンロード: [v1.1.1](https://github.com/kan8223-dotcom/th06-psp-native/releases/tag/v1.1.1)

2026-10-15のプレビュー版は、利用者自身の`gm.dls`を使ったMIDI演奏に対応しています。
MEの完了をメインCPUで空回しして待つ処理を撤回し、待機中はゲーム側へCPUを返す方式にしました。

PSP-1000では、待機修正前のMIDI開発版で1～6面、ED、結果画面、タイトル復帰、スコア保存を
実機ログで確認しています。現行版の実機ログは5面進行後のタイトル復帰までで、操作が軽くなったとの
利用者報告があります。PSP-3000の現行版での通しプレイ成功も利用者からの報告です。
これらは、60fpsや音切れゼロ、WindowsのMSGSとの完全な音声一致を保証するものではありません。

- PSPのGraphics Engine（GE）を使用していますが、GPU/GE向け最適化は未完です。
- 背景・立ち絵・大量の弾消去など描画量の多い場面では処理落ちし、30fps以下になる場合もあります。
- MIDIは利用者自身の `gm.dls` を配置して使用できます。下記の手順を参照してください。
- MIDI再生はゲームプレイのパフォーマンスを低下させます。ME使用時も処理落ちが増える場合があります。
  パフォーマンスを優先する場合は、BGMをWAVにしてください。
- MIDIの音切れは未解決です。現行版でも4面の区間に音声供給不足が実機ログに残っています。
- Memory Stick読み込み中の短い引っかかりが残っています。
- PSP Goの本体ストレージとMemory Stick Microの自動検索はPPSSPPで確認済みですが、PSP Go実機では未確認です。
- PPSSPPでの動作だけでは実機互換を保証しません。
- セーブデータやリプレイの互換性・完全性は保証しません。

不完全なプレビュー版であることを理解したうえで使用してください。

## インストール

必要なもの:

- CFWでhomebrewを起動できるPSP
- 本リポジトリのReleasesにある配布ZIP（EBOOT.PBP同梱）
- 利用者自身が所有するPC版東方紅魔郷1.02fのインストールフォルダ

### CFW互換性

以下は過去の公開版についての記録です。今回のMIDI対応版を全CFWで再検証したものではありません。

- **PSP-1000 / 6.60 PRO-B10**: 公開済みのv1.0.0では2面終了後のクラッシュを実機で再現しました。
  v1.0.1修正版では、PSP-1000実機で1面から6面までの全ステージ遷移に成功しています。
- **6.61 PRO CFW**: v1.0.0相当で2面終了後にクラッシュする場合があるとの報告があります。
  v1.0.1修正版での再確認はまだありません。
- **6.61 LME** および **ARK-5**: 同じ症状は報告されていませんが、網羅的な互換確認ではありません。

各CFW・本体機種・設定の組み合わせを網羅して検証したものではありません。

推奨手順:

1. 配布ZIPの`TH06PSP`フォルダを、メモリースティックの`PSP/GAME/`へコピーします。
2. PC版東方紅魔郷のインストールフォルダを、フォルダごと`TH06PSP`の中へコピーします。
3. コピーした原作フォルダの名前を半角ASCIIの`th6`にします。
4. XMBのゲーム一覧から`Touhou 6 PSP Native`を起動します。

コピー元とコピー先を並べた例です。左側のPC版フォルダ（この例では`kouma`）を右側の
`TH06PSP`へフォルダごとコピーし、コピー後のフォルダ名を`th6`にします。

![PC版の原作フォルダをTH06PSPへコピーする例](docs/images/install-01-copy-folder.png)

### データフォルダの自動検索（任意）

原作フォルダを`TH06PSP`の中へ置かず、メモリースティックまたはPSP Goの本体ストレージ直下へ
置くこともできます。フォルダ名は問いません。例えば次の配置を自動検出します。

```text
ms0:/kouma/    ← メモリースティック、PSP GoではMemory Stick Micro
ms0:/th6/
ef0:/kouma/    ← PSP Goの本体ストレージ
ef0:/th6/
```

起動時は、EBOOTと同じ場所の`th6`、実際にEBOOTを起動したデバイスの直下、もう一方の
`ms0:`/`ef0:`の順で調べます。デバイス直下のフォルダは1階層だけ検索し、6個のDATの
ファイルサイズと`PBG3`ヘッダが一致し、17曲のWAVがすべて揃ったフォルダだけを採用します。
メモリースティック全体を再帰検索することはありません。

起動時にSELECTを押し続けると、検出したデータフォルダの選択画面を開けます。`AUTO`または
使用するフォルダを上下キーで選び、×ボタンまたはSTARTで決定します。選択した場所は
`TH06PSP/TH06PSP_DATA_PATH.TXT`へ保存されます。保存先が取り外された場合や移動した場合は、
次回起動時に自動検索へ戻ります。選択画面で`AUTO`を決定すると保存指定を解除できます。

最終的な配置は次の形です。

```text
PSP/GAME/TH06PSP/
├── EBOOT.PBP
├── NotoSansJP-Regular.ttf
├── msgothic.ttc                 ← 任意。MSゴシックを使う場合だけ自分で配置（非同梱）
├── README.md
├── README_EN.md
├── CREDITS.md
├── LICENSE
├── licenses/
└── th6/                         ← 利用者が自分でコピーする原作フォルダ
    ├── 東方紅魔郷.exe
    ├── 紅魔郷CM.DAT
    ├── 紅魔郷ED.DAT
    ├── 紅魔郷IN.DAT
    ├── 紅魔郷MD.DAT
    ├── 紅魔郷ST.DAT
    ├── 紅魔郷TL.DAT
    ├── gm.dls                   ← 任意。MIDIを使う場合だけ自分で配置
    └── bgm/
        ├── th06_01.wav
        └── ... th06_17.wav
```

MSゴシックを使う場合は、自分のWindowsにある `C:\Windows\Fonts\msgothic.ttc` を
`PSP/GAME/TH06PSP/msgothic.ttc`（EBOOTと同じ場所）へコピーしてください。配置は任意です。
MSゴシックを優先して読み込み、無い場合や読み込めない場合は同梱の `NotoSansJP-Regular.ttf` を使います。
`msgothic.ttc` はMicrosoftのフォントのため同梱しません。GitHubや不具合報告にも添付しないでください。

原作フォルダ内にある6個のDATファイルを確認する例です。

![原作フォルダ内の6個のDATファイル](docs/images/install-02-dat-files-reference.png)

> [!NOTE]
> 画像右側の`KOUMAKYO_*.dat`は開発時に英名へ変更して確認した配置です。この配置でも動作しますが、
> 現行版では左側の日本語ファイル名のままフォルダごとコピーできるため、個別の選別や改名は不要です。

どの配置でも、原作フォルダの中身を選別・改名する必要はありません。日本語名DATは、PSPのFATドライバで直接開けない
場合も、ファイルサイズと`PBG3`ヘッダから自動的に識別します。原作フォルダは読み取り専用として扱い、
PSP側の設定、スコア、新しく保存したリプレイは`TH06PSP`直下へ分離します。

6個の原作DATと17曲のWAVが揃っていない場合、ゲーム本体へ入らず、画面に不足を表示して終了します。

## MIDI演奏：MSGSの音色ファイルを使う（任意）

**利用者自身のMSGS音色ファイル `gm.dls` をメモリースティックに置くと、OptionでMIDIを選んで再生できます。**
PSP側の合成器でリアルタイム演奏します。WindowsのMSGSプログラムそのものを動かすものではありません。

MIDI再生には合成処理の負荷があり、ゲームプレイのパフォーマンスが低下します。ME使用時も処理落ちが
増える場合があります。パフォーマンスを優先する場合は、BGMをWAVにしてください。

1. 自分のWindows PCにある `C:\Windows\System32\drivers\gm.dls` を用意します。
2. `PSP/GAME/TH06PSP/th6/gm.dls` へ、名前を変えずにコピーします。
   原作フォルダを別の場所に置いた場合は、その選択済み原作フォルダの直下に置いてください。
3. ゲームを起動します。初回は原作MIDI曲が使う音色を読み込み、
   `PSP/GAME/TH06PSP/MIDICACHE.BIN`（約1.2MB）を自動作成します。初回は時間がかかります。
4. タイトル画面のOptionでBGMを「MIDI」にします。

キャッシュ作成後も `gm.dls` を残してください。MIDI利用時も原作DAT6個とWAV17曲は必要です。
SF2ファイルやWindowsのMSGSプログラム本体をコピーする必要はありません。
音源変更後も古いキャッシュが使われる場合は、`MIDICACHE.BIN` を削除して再起動すると再作成します。

PSP-1000/2000/3000とも、通常はMEでMIDIを合成します。PSP-3000もMEを使用します。
PSP-2000/3000などの64MB機には、MEを利用できない場合や設定でMEを無効にした場合の
予備経路として、メインCPU（SC）での合成もあります。PSP-1000ではMIDIにMEが必要です。
`gm.dls` が無い場合やMIDIを利用できない場合はWAVへ戻ります。

`gm.dls` はMicrosoftの著作物です。音源、音色・波形データ、生成キャッシュ、原作MIDI曲は配布しません。
利用者自身のファイルを用意し、これらをGitHubや不具合報告へ添付しないでください。

## ビルド

PSPDEV/PSPSDKが`/usr/local/pspdev`に導入済みで、CMake、Python、`xxd`が使える環境で実行します。
同梱したm-c/d MECCも初回の`make`でsourceからbuildします。
MIDI合成器とシーケンサの共通ソースは`third_party/touhou_dls_common`に同梱しています。
別のローカルリポジトリや音源ファイルなしでプログラムをビルドできます。

```sh
make -j"$(nproc)" all
./psp_preflight.sh --post
make release
```

`make release`は`dist/th06-psp-native-preview.zip`を作ります。ZIPにはEBOOT、再配布可能な日本語フォント、
日本語・英語README、Credits、各ライセンスだけが入り、原作データとリプレイは入りません。
